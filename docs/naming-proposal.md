# 網站命名一致性提案

這份文件只提出顯示名稱建議，尚未修改正式導覽文字或路由。目標是讓 Blog、Journal、Literature、Papers 與 Paper Lens 的角色更清楚，避免使用者以為不同頁面在做同一件事。

| 功能 | 現有名稱 | 建議顯示名稱 | 保留路由 | 原因 |
| --- | --- | --- | --- | --- |
| Dashboard | 儀表板、Dashboard | 研究儀表板 | `/dashboard` | 作為任務、週報、日誌與文獻的總覽首頁，中文名稱較貼近網站用途。 |
| Blog | 學習日誌、Blog、研究日誌 | 研究日誌 | `/blog` | Blog 主要呈現正式整理過的研究與開發紀錄，比「學習日誌」更能涵蓋目前內容。 |
| Blog Admin | 快速撰寫日誌、Blog 撰寫器 | 研究日誌撰寫 | `/blog/admin` | 與 `/blog` 對應，強調發布後會出現在研究日誌頁。 |
| Journal | 研究筆記、Notes | 研究筆記 | `/journal` | Journal 適合保留為想法、片段紀錄與未整理素材，和正式日誌分開。 |
| Journal Admin | 筆記撰寫、研究筆記撰寫 | 研究筆記撰寫 | `/journal/admin` | 保留為非正式筆記入口，避免和 Blog 發布流程混淆。 |
| Literature Search | Literature、文獻導航、文獻總結系統 | 文獻搜尋與分析 | `/literature` | 此頁同時包含搜尋、分析提示與 Paper Lens，名稱可同時涵蓋兩種工作。 |
| Paper Lens | Paper Lens 分析、文獻分析 | Paper Lens | `/literature` | 建議作為 `/literature` 內的功能區塊，不另外建立第二個同名入口。 |
| Saved Papers | Papers、文獻庫、我的文獻庫 | 文獻庫 | `/papers` | 用來保存想繼續閱讀的論文、閱讀狀態與分析紀錄，名稱清楚。 |
| Tasks | 任務、Tasks、研究任務 | 研究任務 | `/tasks` | 比單純「任務」更能區分一般待辦事項與研究工作。 |
| Tasks Admin | 任務管理入口、新增任務 | 研究任務管理 | `/tasks/admin` | 強調這是本人登入後的管理頁。 |
| Weekly | 週報、Weekly、研究週報 | 研究週報 | `/weekly` | 與研究任務、研究日誌保持一致。 |
| Categories | 所有分類、文章分類 | 文章分類 | `/categories` | 明確表示分類對象是 Blog 文章。 |
| Tags | 所有標籤、文章標籤 | 文章標籤 | `/tags` | 明確表示標籤對象是 Blog 文章。 |
| Login | 登入、Login | 登入 | `/login` | Header 可維持簡潔；若未來訪客登入角色更完整，再改為「登入 / 訪客」。 |
| About | 關於我、About | 關於這個網站 | `/about` | 目前內容更偏網站用途與研究方向介紹，不一定是完整個人履歷。 |

## 建議採用方向

第一階段建議只調整顯示文字，不改路由，降低外部連結失效風險。若要最小幅度改善導覽清楚度，可以優先使用以下名稱：

- 研究儀表板
- 研究日誌
- 研究筆記
- 研究任務
- 研究週報
- 文獻搜尋與分析
- 文獻庫
- 關於這個網站

## 需要人工確認

- `/blog` 是否要繼續稱為「學習日誌」，還是改為較正式的「研究日誌」。
- `/journal` 是否只保存未整理想法，或也要成為長期筆記資料庫。
- Paper Lens 是否維持在 `/literature` 中，還是未來需要獨立頁面。
- `/about` 是否要補上正式學校、實驗室、研究題目與聯絡方式。
